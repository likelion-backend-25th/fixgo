## 1.1 기획 개요

### 1.1.1 프로젝트 배경 및 목적
- 매일 체계적인 학습 루틴을 형성하고 개발 역량을 단계별로 증명하는 개발자 맞춤형 통합 학습 관리 플랫폼(LMS, Learning Management System) 하루배움 구축.
- 강사의 전문 지식 전달, 수강생의 차시별 진도율 추적 및 과제 피드백, 플랫폼 관리자의 매출 및 정산 자동화를 유기적으로 연결하는 종합 엔터프라이즈 관리 시스템 구현.
- Spring Boot와 Spring Data JPA 기반의 고성능 도메인 아키텍처와 React 기반 SPA 클라이언트 간 RESTful 비동기 통신 체계 완성.
- 대규모 수강 데이터의 안정적인 처리와 자정 주기 정산/만료 자동화를 위한 Spring Batch 및 Docker, GitHub Actions 기반 CI/CD 배포 자동화 인프라 체계 확립.

### 1.1.2 서비스 핵심 가치
- 역할 기반의 정교한 접근 제어(RBAC): 수강생(STUDENT), 강사(INSTRUCTOR), 관리자(ADMIN)로 역할을 명확히 분리하여 안전한 권한별 업무 환경 제공.
- 실무 중심의 인터랙티브 학습 경험: 챕터 및 차시 단위 커리큘럼 스트리밍, 동영상 이어보기 진도율 추적, 과제 제출 및 강사 피드백 시스템 통합.
- 투명하고 안정적인 거래 프로세스: 외부 전자결제(PG) 연동 기반의 강좌 결제, 환불 정책 검증, 쿠폰/할인 적용 및 웹훅 기반 데이터 정합성 보장.
- 대용량 데이터 배치 자동화: Spring Batch를 통한 수강 기간 만료 자동 처리, 강사별 일일/월간 매출 정산, 수강 통계 집계의 무인화.
- AI 기반 학사/행정 운영 자동화 챗봇: 강좌 커리큘럼 문의, 결제 및 영수증 발급, 환불 정책, 수료 기준 안내 등 기존에 과정 운영자가 수동으로 응대하던 반복적인 학사·행정 문의를 AI가 24시간 대신 자동 처리하여 운영 업무 효율 극대화.

### 1.1.3 기대 효과
- 교육 운영 자동화를 통한 관리 비용 절감 및 플랫폼 운영 효율성 제고.
- 차시별 진도율 시각화와 과제 피드백을 통한 수강생 완강률 증대.
- 객관적인 학습 성취도 지표(진도율, 과제 점수)를 바탕으로 한 수료증 자동 발급.

## 1.2 주요 기능 요구사항

### 1.2.1 회원 및 다중 역할 인증 관리 (Auth & Member)
- 회원가입 및 본인 인증: 이메일 기반 기본 가입, 필수 프로필 입력 및 역할(수강생/강사) 선택.
- 보안 인증 체계: Spring Security 및 JWT(JSON Web Token) 기반 무상태 인증, RTR(Refresh Token Rotation) 토큰 갱신 전략 적용.
- OAuth2 소셜 로그인: 카카오, 구글 간편 연동 및 최초 연동 시 회원 정보 자동 동기화.
- 역할 기반 인가(RBAC): Security Filter Chain 및 PreAuthorize 어노테이션을 통한 URL별, 메서드별 세분화된 접근 제어.
- 내 계정 정보 관리: 프로필 정보(닉네임, 프로필 이미지) 수정, 비밀번호 변경 및 회원 탈퇴.

### 1.2.2 강좌 및 커리큘럼 관리 (Course & Curriculum)
- 강좌 등록 및 관리: 강사 전용 강좌 개설, 썸네일 이미지 및 소개 자료 업로드(AWS S3), 수강료 및 수강 가능 일수 설정.
- 다계층 커리큘럼 구성: 강좌 하위 대단원(Chapter) 및 소단원(Lesson) 계층형 등록, 동영상 URL 및 강의 자료 첨부.
- 강좌 승인 워크플로우: 강사의 강좌 개설 요청 후 관리자 심사 및 최종 승인/반려 상태 제어.
- 다중 필터 강좌 탐색: 카테고리(백엔드, 프론트엔드, 인프라 등), 난이도, 강사명 기반 복합 검색(QueryDSL 적용).

### 1.2.3 수강 신청 및 주문/결제 관리 (Order & Payment)
- 장바구니 및 단건 주문: 다중 강좌 일괄 담기, 쿠폰 적용을 통한 최종 결제 금액 산출.
- PG 결제 연동: 포트원(아임포트) 브라우저 SDK 연동, 신용카드 및 간편결제 지원.
- 결제 위변조 방지: 결제 사전 검증(금액 사전 등록) 및 사후 검증(PG사 결제 내역 단건 조회 대조) 트랜잭션 보장.
- 결제 웹훅(Webhook) 처리: 네트워크 지연이나 브라우저 이탈 시에도 결제 승인 상태를 안전하게 반영하는 비동기 웹훅 처리.
- 환불 및 결제 취소: 수강 시작 전 전액 환불, 진도율 기준 부분 환불 정책에 따른 자동 환불 트랜잭션.
- 주문 및 결제 내역 조회: 본인의 과거 주문 내역, 결제 금액, 결제 영수증 출력 및 환불 처리 상태 조회.

### 1.2.4 학습 진도 및 과제 평가 관리 (Learning & Assignment)
- 나의 수강 현황 대시보드: 수강 중인 강좌 목록, 강좌별 학습 진도율 및 최근 시청 차시 이어보기 제공.
- 진도율 실시간 추적: 수강생의 동영상 재생 위치(초 단위) 자동 저장, 80% 이상 수강 시 해당 차시 자동 완료 처리.
- 전체 강좌 진도율 산출: 강좌 내 완료된 차시 수 기반 종합 진도율 백분율(%) 계산 및 대시보드 시각화.
- 과제 출제 및 제출: 강사의 차시별 과제 가이드 등록, 수강생의 코드/과제 파일 첨부 제출.
- 강사 채점 및 피드백: 제출된 과제에 대한 평가 점수 부여 및 상세 피드백 작성, 학생 알림 전송.
- 수료증 자동 발급: 수강 기간 내 진도율 100% 및 과제 통과 시 수료증 생성 및 PDF 다운로드 지원.

### 1.2.5 학습 커뮤니티 및 알림 관리 (Community & Notification)
- 강의별 질의응답(Q&A): 차시별 특정 재생 시점에 질문 등록, 코드 블록 작성 지원, 강사 및 조교 답변 등록.
- 수강 후기 및 평점: 수강 완료 수강생만 작성 가능한 리뷰 시스템, 강좌별 평균 별점 자동 계산.
- 실시간 알림: 과제 피드백 등록, Q&A 답변 등록, 수강 만료 임박 시 사용자 알림 발송.

### 1.2.6 배치 및 백오피스 통계 관리 (Batch & Admin Dashboard)
- 수강 만료 자동화 배치: 매일 자정 Spring Batch를 구동하여 수강 만료일이 도래한 수강권의 상태를 수강 완료로 일괄 갱신.
- 일일/월간 정산 배치: 매월 1일 강사별 강좌 수강료 매출 집계, 플랫폼 수수료 공제 후 최종 정산금 산출 및 대용량 일괄 저장.
- 관리자 통계 대시보드: 일일 활성 수강생(DAU), 일자별 신규 매출, 인기 강좌 랭킹, 강사별 정산 내역 지표 시각화.

### 1.2.7 AI 기반 학사 행정 지원 챗봇 (AI Administrative Assistant)
- 개설 강좌 및 커리큘럼 문의 자동 응답: 강좌별 선수 지식 요건, 학습 목표, 추천 대상, 차시별 목차 및 강사 프로필 정보 안내.
- 수강 신청, 결제 및 영수증 발급 안내: 결제 수단 종류, 수강 바우처 및 쿠폰 적용 방법, 사업자/개인 결제 영수증 출력 절차 가이드.
- 환불 규정 및 수강 취소 절차 안내: 수강 시작 전/후 잔여일수 및 진도율에 따른 환불 정책 계산 기준과 취소 접수 방법 안내.
- 수료 기준 및 학사 일정 안내: 강좌별 수료 인정 진도율(예: 80% 이상), 필수 과제 제출 기준, 수료증 PDF 발급 방법 및 수강 기간 연장 규정 안내.
- 운영자 반복 업무 무인화: 기존에 과정 운영자(매니저)가 1:1 채널에서 수동으로 일일이 응대하던 단순·반복적인 학사 및 행정 문의를 24시간 실시간 자동 처리.

## 1.3 비기능 요구사항 및 기술 스택

### 1.3.1 시스템 아키텍처 및 기술 스택
- 백엔드 코어: Java 25, Spring Boot 4.x, Gradle 9.x
- 영속성 및 ORM: Spring Data JPA, Hibernate, OpenFeign QueryDSL 7.x
- 배치 처리: Spring Batch 6.x
- AI 어시스턴트: OpenAI / Gemini API, Spring AI 및 WebClient 기반 비동기 스트리밍(SSE) 연동
- 데이터베이스: MySQL 9.x (9.7, 운영), H2 Database (단위 테스트)
- 보안 및 인증: Spring Security 6.x, JJWT, OAuth2 Client
- 클라우드 인프라: AWS EC2, RDS (MySQL), S3 (미디어 자산), CloudFront
- 컨테이너 및 CI/CD: Docker, Docker Compose, GitHub Actions 기반 CI/CD 배포 자동화 파이프라인
- 프론트엔드: React 19.x, TypeScript 6.x, Vite 8.x, Tailwind CSS 4.x, Zustand 5.x, Axios

### 1.3.2 데이터 정합성 및 성능 최적화
- 선언적 트랜잭션 관리: 주문-결제-수강권 발급 간 원자성(@Transactional) 확보.
- JPA 쿼리 최적화: Fetch Join과 DTO 직접 조회를 통한 N+1 쿼리 병목 제거.
- 대용량 배치 안전성: 커서/페이징 기반 Chunk 지향 프로세싱 적용으로 메모리 고갈 방지.

## 1.4 팀 구성 및 도메인별 역할 분담

### 1.4.1 팀 구성 개요
- PM (Project Manager): 용쌤 (프로젝트 총괄, 일정 관리, 회원/인증, 결제 및 배치 아키텍처)
- PL (Project Leader): 나무 (기술 리딩, 공통 설계, 강좌/커리큘럼, 학습 진도 및 과제 평가)
- 팀원 (Developer): 하루 (프론트엔드 UI/UX, AI 학사 행정 지원 챗봇, GitHub Actions CI/CD 인프라)

### 1.4.2 도메인별 상세 역할 및 산출물 분담
| 담당자 (직책) | 도메인 | 주요 담당 업무 | 핵심 산출물 |
|---|---|---|---|
| 용쌤 (PM) | 인증 및 회원 관리 (Auth/Member) | Security 설정, JWT 토큰 발급/재발급, OAuth2 연동, 다중 역할(RBAC) 분기 | SecurityConfig, JwtAuthenticationFilter, MemberController |
| 나무 (PL) | 강좌 및 커리큘럼 (Course/Curriculum) | 강좌 등록/수정/승인, 챕터-차시 구조 설계, OpenFeign QueryDSL 동적 검색 | CourseService, CourseQueryRepository, CurriculumController |
| 용쌤 (PM) | 주문 및 결제 관리 (Order/Payment) | 장바구니, 포트원 PG 연동, 결제 사전/사후 검증, 결제 웹훅, 환불 처리 | OrderService, PaymentClient, PaymentWebhookController |
| 나무 (PL) | 학습 및 과제 관리 (Learning/Assignment) | 동영상 진도율 추적, 과제 제출/채점, 수료증 자동 발급, Q&A 게시판 | LearningProgressService, AssignmentService, S3FileService |
| 하루 (팀원) | AI 학사 행정 챗봇 (AI Admin Assistant) | 학사 규정/강좌 FAQ 프롬프트 엔지니어링, RAG 기반 행정 데이터 연동, SSE 스트리밍 API | AiAdminChatService, AiChatbotController, AdminFaqPrompt |
| 용쌤 (PM) | 배치 및 관리자 통계 (Batch/Admin) | 수강 만료 자동화 Job, 월간 매출 정산 Job, 관리자 통계 대시보드 API | ExpiredEnrollmentBatchConfig, SettlementBatchConfig, AdminService |
| 하루 (팀원) | 인프라 및 프론트엔드 연동 (Infra/Frontend) | Docker Compose 패키징, GitHub Actions CI/CD 구축, React 화면 및 API 연동 | Dockerfile, docker-compose.yml, github-actions.yml, React UI |
